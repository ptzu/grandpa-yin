# 定價與毛利分析

> 版本：pricing-v1（2026-08）。此文件記錄點數幣值、各服務定價、毛利率算法與依據。
> 實際生效值以 `config/settings.yml` 為準；改價後請跑 `python3 -m src.core.settings` 驗證。

## 設計原則

1. **點數/台幣 > 1**：1 NT$ 買到約 3 點，數字大、單價低，強化「超值感」。
2. **非 1:1、且各包匯率不同**：售價收尾在 9、點數整百，每點單價是 0.32~0.37 的醜零頭，
   長輩／子女無法心算「一次幾塊」。
3. **點/NT$ 隨包變大而遞增**：這就是唯一要顧的階梯條件——大包永遠最划算。
   （價格 149/299/499/1088 之下，湊兩個小包在「價格」上就已經比上一階貴，
   例如 2×人氣 NT$598 > 超值 NT$499，所以不需要再比「點數」，只看比率即可。）
4. **成本天生極低**：Replicate 一次僅 NT$2.6~3.7，固定月費攤提 < NT$1，
   所以毛利率主要由服務點數（售價）決定，有很大調降空間。

## 成本基準

匯率假設 **USD 1 = NT$32**（2026 當前區間）。

### 變動成本（每次生成）

| 服務 | 模型 | Replicate 實測 | 換算 NT$ | +15% buffer¹ |
|---|---|---|---|---|
| P圖大神 `edit` | google/nano-banana-2 | $0.07 | 2.24 | **≈ 2.6** |
| 修復老照片 `colorize` | google/nano-banana-2 | $0.07 | 2.24 | **≈ 2.6** |
| 照片動起來 `animate` | prunaai/p-video | $0.10 | 3.20 | **≈ 3.7** |

¹ buffer 涵蓋偶發重試、720p 影片價差、Storage 轉存流量。

### 固定成本（每月，與量無關）

| 項目 | 方案 | 月費 |
|---|---|---|
| Railway | 小型 gunicorn 常駐 | ~NT$300–800 |
| Supabase | Pro（成品存 30 天，Free 會休眠不能上線） | ~NT$800 |
| 合計 | | **≈ NT$1,400–1,600/月** |

月量破千次後每次攤提 < NT$1，對毛利率影響 < 2%，故下表毛利率只計變動成本。

### 金流手續費（ECPay）

- 信用卡 ≈ 2.8–3%（比例，已計入下表）。
- 超商代碼每筆固定費（約 NT$25）→ 小額包會被吃掉毛利，**建議小額包只開信用卡**。

## 毛利率算法

```
每點 NT$     = 點數包售價 ÷ 點數        （各包不同）
單次售價     = 服務點數 × 每點 NT$
單次變動成本 = Replicate 成本 + 金流手續費（售價 × 3%）
毛利率       = (單次售價 − 單次變動成本) ÷ 單次售價
```

毛利率是「區間」，因為每點單價依用戶從哪個包扣點而不同：

| 點數包 | 售價÷點數 | 每點 NT$ | 備註 |
|---|---|---|---|
| 體驗 | 149 / 400 | 0.373 | 對我方最有利（上緣） |
| 人氣 | 299 / 850 | 0.352 | |
| 超值 | 499 / 1,500 | 0.333 | |
| 家庭 | 1,088 / 3,400 | 0.320 | **地板，最不利（下緣）** |

**實例（老照片 25 點、用家庭包扣點）：**

```
單次售價   = 25 × 0.320 = NT$8.00
金流手續費 = 8.00 × 3%  = 0.24
變動成本   = 2.6 + 0.24 = 2.84
毛利率     = (8.00 − 2.84) ÷ 8.00 = 64.5%
```

## 定案（pricing-v1）

### 點數包

| 點數包 | 售價 NT$ | 點數 | 點/NT$ | 每點 NT$ |
|---|---|---|---|---|
| 體驗包 | 149 | 400 | 2.68 | 0.373 |
| 人氣包 | 299 | 850 | 2.84 | 0.352 |
| 超值包 | 499 | 1,500 | 3.01 | 0.333 |
| 家庭包 | 1,088 | 3,400 | 3.13 | 0.320 |

點/NT$ 一路遞增（2.68→2.84→3.01→3.13），大包永遠最划算；且 2×人氣（NT$598）已比超值（NT$499）貴，湊小包不划算。

### 各服務點數、售價與毛利率

| 服務 | 點數 | 換算售價 | Replicate | **毛利率** |
|---|---|---|---|---|
| P圖大神 `edit` | 20 | NT$6.4 – 7.5 | 2.6 | **56% – 62%** |
| 修復老照片 `colorize` | 25 | NT$8.0 – 9.3 | 2.6 | **64% – 69%** |
| 照片動起來 `animate` | 50 | NT$16.0 – 18.7 | 3.7 | **74% – 77%** |

### 新會員贈點

`welcome_points: 100` = 免費 4 次修復或 2 次動起來，當試用鉤子；獲客成本約 NT$6.5/人。

## 觀察與後續槓桿

- **P圖毛利地板 56%** 是全站最薄的一項（家庭包每點 NT$0.32，售價 NT$6.4 對成本 NT$2.6）。
  要保毛利可把 P圖拉到 22 點；要再降只能先換更便宜的 edit 模型。
- 想再拉高毛利：續降超值/家庭點數（比率再往下，只要維持遞增即可）。
- 想更超值（純外觀，不影響毛利）：拉大點數刻度到 5:1、10:1。
- 匯率若抓更保守（33–34），毛利率頂多差 1%。
